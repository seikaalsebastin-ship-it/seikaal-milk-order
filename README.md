# Seikaal Farm Fresh Milk Order Portal

A static, mobile-friendly order portal for Seikaal Farm Fresh Milk.

## Publish with GitHub Pages (free)

1. Sign in to GitHub and create a **Public** repository, for example `seikaal-milk-order`.
2. Upload `index.html`, `README.md`, and `LICENSE` from this folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. Wait for the Pages deployment to finish. GitHub will show the public website URL in **Settings → Pages**.
7. Open that URL on a phone and use the browser's **Share → Create QR code** option (or any QR generator) to make a scan-to-open QR code.

## Important

- This is a static website; it does not require a server or database to display.
- The existing HTML has been retained as the website's `index.html` without redesigning its layout.
- Check the order submission method and contact details in the HTML before publishing. GitHub Pages does not itself receive or store orders.
- If the HTML references any external services, those services must remain available for the corresponding feature to work.

## Local preview

Open `index.html` in a modern browser.
